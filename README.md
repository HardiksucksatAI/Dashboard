# Daily Focus

A lightweight daily planner for habits, focused work, and tasks. This public edition contains three sections: **Today**, **Focus**, and **Board**.

## Use

- Start with five general habits or add your own.
- Add focus areas and tasks. Choose a 25-, 45-, or 50-minute focus session.
- Move tasks through Active, Waiting On, Someday, and Done.
- Open **Data & backup** to download or restore a JSON backup.

## Saving and privacy

Progress is stored in the current browser. There are no accounts or cross-device synchronization. Clearing browser data removes locally saved progress; keep a downloaded backup. Do not upload personal backup files to this public repository.

The public edition uses its own storage key and backup format. It does not read or replace data from the personal dashboard. It excludes the personal study material, notes, quizzes, school subjects, and Google Drive links.

Running and paused timers survive refreshes. Completed focus sessions are saved once and count on their completion date. Subject and duration stay fixed during a session, including while paused. Breaks start manually.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
2. Under **Settings → Pages**, select **Deploy from a branch**.
3. Select **main** and **/ (root)**, then save.

No installation or build step is required. The source is a single static HTML file.

This is an early public version. Please report problems through the repository's Issues tab.
